# Java 객체지향 프로그래밍 실습 문제

## 문제 1. 직원 급여 시스템

직원 클래스와 하위 클래스들을 구현하고, `Manager`, `SalesPerson`, `Engineer` 객체를 생성하여 각 객체의 필드와 기능을 사용해 보세요.

### 요구사항

**1. 부모 클래스: `Employee`**

- 필드
  - `name`: 직원 이름
  - `id`: 직원 고유번호
  - `basicSalary`: 기본급
- 메소드
  - `calculateSalary()`: 급여 계산

**2. 하위 클래스: `Manager`**

- 필드
  - `managerialBonus`: 관리자 수당
- 메소드
  - `calculateSalary()` 오버라이드
  - 최종 급여 = 기본급 + 관리자 수당

**3. 하위 클래스: `SalesPerson`**

- 필드
  - `commission`: 판매 수당
- 메소드
  - `calculateSalary()` 오버라이드
  - 최종 급여 = 기본급 + 판매 수당

**4. 하위 클래스: `Engineer`**

- 필드
  - `techBonus`: 기술 수당
- 메소드
  - `calculateSalary()` 오버라이드
  - 최종 급여 = 기본급 + 기술 수당

### 실습 과제

- 부모 클래스 `Employee`를 구현하세요.
- 세 개의 하위 클래스에서 상속과 메소드 오버라이딩을 구현하세요.
- 각 클래스의 객체를 생성하고 `calculateSalary()` 메소드를 호출하여 급여를 확인하세요.

## 문제 2. 학생 정보 관리 시스템

요구사항에 맞는 접근 제한자를 사용하여 `Student` 클래스를 구현하세요.

### 요구사항

- 학번(`studentId`): 조회만 가능하고 변경할 수 없어야 합니다.
- 성적(`grades`): 같은 패키지의 교사 클래스에서만 수정할 수 있어야 합니다.
- 이름(`name`), 나이(`age`): 누구나 접근할 수 있어야 합니다.
- 상담 내용(`counselingNotes`): 상담교사 클래스만 접근할 수 있어야 합니다.
- 학생 평가(`evaluation`): `Student` 클래스 내부에서만 관리할 수 있어야 합니다.

### 필드

| 필드 이름 | 의미 |
|---|---|
| `studentId` | 학번 |
| `name` | 이름 |
| `age` | 나이 |
| `grades` | 성적 |
| `counselingNotes` | 상담 내용 |
| `evaluation` | 학생 평가 |

### 실습 과제

각 필드의 접근 범위와 수정 가능 여부를 고려하여 적절한 접근 제한자를 사용하세요.

## 문제 3. 배달 서비스 시스템

`DeliveryService` 추상 클래스와 이를 상속받는 하위 클래스들을 구현하세요.

### 요구사항

**1. 추상 클래스: `DeliveryService`**

- 필드
  - `orderId`: 주문번호
  - `address`: 배달 주소
  - `estimatedTime`: 예상 배달 시간
- 추상 메소드
  - `acceptOrder()`: 주문 접수
  - `deliver()`: 배달 실행
  - `completeDelivery()`: 배달 완료

**2. 하위 클래스**

- `FoodDelivery`: 음식 배달
- `PackageDelivery`: 택배 배달

각 하위 클래스에서 부모 클래스의 추상 메소드를 구현하세요.

### 출력 예시

```text
치킨 주문이 접수되었습니다.
배달 예상 시간: 40분
배달이 완료되었습니다.

=== 택배 배달 테스트 ===
택배 주문이 접수되었습니다.
배달 예상 시간: 2시간
배달이 완료되었습니다.
```

### 실습 과제

- `DeliveryService`를 추상 클래스로 구현하세요.
- `FoodDelivery`와 `PackageDelivery` 클래스에서 추상 메소드를 오버라이딩하세요.
- 각 객체를 생성하고 주문 접수부터 배달 완료까지의 과정을 출력하세요.

## 문제 4. 여행 패키지 시스템

`TravelPackage` 부모 클래스와 이를 상속받는 `HoneymoonPackage` 클래스를 구현하세요.

**각 생성자에서는 필드 초기화 과정을 출력해야 합니다.**

### 요구사항

**1. 부모 클래스: `TravelPackage`**

- 필드
  - `packageId`: 패키지 ID
  - `destination`: 목적지
  - `price`: 가격

**2. 하위 클래스: `HoneymoonPackage`**

- 추가 필드
  - `hotelGrade`: 호텔 등급
  - `specialService`: 특별 서비스

### 출력 예시

```text
== 부모 클래스 생성자 ==
패키지ID 초기화: BALI001
목적지 초기화: 발리
가격 초기화: 2500000
== 자식 클래스 생성자 ==
호텔등급 초기화: 5성급
스페셜서비스 초기화: 스파패키지
```

### 테스트 코드

아래 코드를 실행했을 때 출력 예시와 같은 결과가 나오도록 클래스를 구현하세요.

```java
HoneymoonPackage honeymoon = new HoneymoonPackage(
    "BALI001",
    "발리",
    2500000,
    "5성급",
    "스파패키지"
);
```

### 실습 과제

- `TravelPackage` 부모 클래스를 구현하세요.
- `HoneymoonPackage`에서 `TravelPackage`를 상속받으세요.
- `super()`를 사용하여 부모 클래스의 필드를 초기화하세요.
- 부모 생성자와 자식 생성자의 실행 순서 및 필드 초기화 과정을 출력하세요.
