### 1. 실행 결과 예측 문제

**Q. 위 코드의 실행 결과는 무엇일까요?**

```java
public class Main {
    public static void main(String[] args) {
        int a = 10;
        double b = 3.5;
        System.out.println(a + b);
    }
}
```
