## 문제 5. 로그인 및 로그아웃 메소드 구현하기

`MemberService` 클래스에 `login()` 메소드와 `logout()` 메소드를 선언하세요.

### 요구사항

**1. `login()` 메소드**

- 매개변수로 아이디(`id`)와 비밀번호(`password`)를 전달받습니다.
- 아이디가 `"hong"`이고 비밀번호가 `"12345"`인 경우에만 `true`를 반환합니다.
- 그 외의 경우에는 `false`를 반환합니다.

**2. `logout()` 메소드**

- 매개변수로 아이디(`id`)를 전달받습니다.
- 메소드를 호출하면 `"로그아웃 되었습니다."`를 출력합니다.

### 메소드 명세

| 리턴 타입 | 메소드 이름 | 매개변수 |
|---|---|---|
| `boolean` | `login` | `String id`, `String password` |
| `void` | `logout` | `String id` |

### 실행 예제

아래의 `MemberServiceExample` 클래스를 실행하여 결과를 확인하세요.

```java
public class MemberServiceExample {

    public static void main(String[] args) {
        MemberService memberService = new MemberService();

        boolean result = memberService.login("hong", "12345");

        if (result) {
            System.out.println("로그인 되었습니다.");
            memberService.logout("hong");
        } else {
            System.out.println("id 또는 password가 올바르지 않습니다.");
        }
    }
}
```

**[실행 결과]**

```text
로그인 되었습니다.
로그아웃 되었습니다.
```

## 문제 6. 상품 관리 시스템 클래스 만들기

상품 관리 시스템에서 사용할 `Product` 클래스를 구현하세요.

### 요구사항

다음의 필드를 선언하세요.

| 필드 의미 | 필드 이름 | 필드 타입 |
|---|---|---|
| 상품코드 | `productCode` | `String` |
| 상품명 | `productName` | `String` |
| 가격 | `price` | `int` |
| 재고수량 | `stockQuantity` | `int` |

**추가 요구사항**

- `Product` 객체를 생성할 때 필드값도 함께 초기화할 수 있도록 생성자를 구현하세요.
- 생성자의 매개변수는 필드에 선언된 정보를 바탕으로 구성하세요.
